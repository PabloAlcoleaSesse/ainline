# ainline 1.0.0

Run your existing AI providers from one small Rust CLI, with shared project context.
The executable is `ai`; the package is `ainline`.

## Included

- Claude, Codex (`oa`), Copilot, Antigravity and Ollama adapters; explicit provider
  selection, model shortcuts, saved defaults and native argument forwarding.
- Named and numbered profiles (`ai2`), agent instructions, linked instruction files,
  and portable profile export/import.
- Reusable tasks with saved profiles, instructions and request flags.
- Project rules, expiring working notes, stack/Git summaries, file attachments and
  explicit Git diffs. Inspect sources with `ai context explain` or full prompts
  with `--dry-run` before sending.
- Piped input, provider diagnostics, bounded output, deadlines, streaming where
  supported, and native failure exit codes.
- `ai doctor`, shell completions, checksum-verified binary installation and Homebrew
  formulas. Provider credentials remain managed by the native provider CLIs.

## Quick start

Install the archive matching your platform or download and review `install.sh` (macOS/Linux):

```sh
sh install.sh v1.0.0
ai setup cl hk4.5
ai doctor
ai explain this project
ai oa review this code
```

The shell installer requires neither Python nor Rust. Install and authenticate
your chosen provider separately. On Windows download `install.py` and use
`py install.py v1.0.0`. The installer defaults to `~/.local/bin`; add it to PATH.

```sh
ai task set review --instructions 'Review correctness and edge cases' --arg=--diff
ai task review --dry-run
ai task review
ai context explain --json
```

## Downloads

Linux x86-64 (glibc), macOS Apple Silicon and Intel, and Windows x86-64 archives are
published with `SHA256SUMS`. The installer checks the selected archive's checksum
before installation. `ainline.rb` is the generated binary Homebrew formula.
See [installation and removal](https://github.com/PabloAlcoleaSesse/ainline/blob/v1.0.0/docs/installation.md).
The package is not published to crates.io.

## Compatibility and limits

This release does not certify every provider/model/account combination. Automated
adapter tests use native local fixtures; native version/help checks are distinct
from live model tests. Review the
[compatibility report](https://github.com/PabloAlcoleaSesse/ainline/blob/v1.0.0/docs/compatibility.md).

Codex and Antigravity responses are buffered. Provider permissions, hooks and local
settings still apply; this wrapper is not a sandbox. Deliberately detached Unix
processes can escape process-group cleanup. Startup depends on project context and
Git; no universal sub-15-ms guarantee is made.

Existing configuration remains supported. Legacy generated OpenAI CLI settings
migrate to Codex; Ollama remains a separate provider. No new features beyond the
prepared 1.0 scope are included.
